# MaxActivity — загрузки

Установщики MaxActivity для Windows x64: [последний выпуск](https://github.com/Ru5C55an/MaxActivity-Releases/releases/latest).

Скачайте `MaxActivity-Setup-ВЕРСИЯ-x64.exe` и запустите установку. Node.js, отдельный Chrome и доступ к приватному репозиторию исходников для работы приложения не нужны. Приложение проверяет новые стабильные версии при запуске и затем раз в шесть часов. При появлении новой версии оно предложит обновиться; скачивание и установка доступны в разделе «Обновления».

В выпусках также находятся файлы `.blockmap` и `latest.yml` для обновления приложения, а также `SHA256SUMS.txt` с контрольными суммами. Исходники и персональные данные аккаунтов здесь не публикуются.

Профили, настройки прокси и авторизацию пользователь добавляет на своём компьютере. Обновление сохраняет локальные данные. Резервные копии каталога данных должны храниться приватно.

Сборка 0.2.0 пока не подписана сертификатом издателя; Windows может показать предупреждение SmartScreen.
